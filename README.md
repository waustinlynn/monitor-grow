# monitor-grow

Serverless grow-environment monitoring application for temperature and humidity telemetry, automated missing-data and out-of-range alerting, and historical dashboards.

## Architecture Summary

Built with a **Full-Stack Go + React 5-Layer Tested Monorepo** architecture:
- **Backend:** Go HTTP API (`chi` + `Huma v2`) on AWS Lambda + HTTP API Gateway v2.
- **Persistence:** DynamoDB On-Demand.
- **Alerting:** EventBridge 1-minute scheduled alerting Lambda + AWS SNS notifications.
- **Frontend:** TypeScript React SPA (`Vite` + `openapi-fetch` + `TanStack Query`) hosted on S3 + CloudFront.
- **Contract:** Code-first OpenAPI 3.1 generated by Huma.

## The 5 Testing Layers

| Layer | Gate | Scope | Real Dependencies | Tooling |
| :--- | :--- | :--- | :--- | :--- |
| **1. Unit** | PR | Pure domain rules, alert evaluation, formatters | None | Go `testing`, Vitest |
| **2. Component** | PR | Full HTTP API: routing, auth, validation, errors | None (fakes) | Go `humatest` |
| **3. Contract** | PR | Zero OpenAPI/TS drift + runtime validation | None | `cmd/openapi`, MSW |
| **4. Integration** | PR | Real DynamoDB adapters & queries | DynamoDB Local | Go `-tags=integration` |
| **5. E2E** | Deploy | Black-box business journeys | Live Env | Playwright |

## Local Development

This project uses `just` as a task runner.

- `just generate-contract` — Regenerate OpenAPI spec and frontend types.
- `just pr-gate` — Run all linting and Layers 1–4 tests (Docker-free).
- `E2E_BASE_URL=<url> just test-e2e` — Run Layer 5 tests against a live environment.
- `just build-lambdas` — Build ARM64 Lambda deployment packages.
